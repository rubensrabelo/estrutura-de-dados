# Entendendo Algoritmos - Estudos

## Descrição
Este repositório contém as minhas implementações e anotações de código desenvolvidas durante a leitura e estudo do livro **Entendendo Algoritmos**. O objetivo principal é fixar os conceitos teóricos de estruturas de dados e lógica algorítmica por meio da prática.

## Tecnologias e Ferramentas
*   **Linguagem principal:** Python 3.x *(substitua se usou outra linguagem, ex: JavaScript, Go, etc.)*
*   **Ambiente de desenvolvimento:** VS Code / Terminal

## Estrutura do Repositório

*   `01_busca_binaria/` — Algoritmo de busca binária e análise de Notação Big O.
*   `02_ordenacao_selecao/` — Implementação do algoritmo de ordenação por seleção.
*   `03_recusa/` — Entendendo a pilha de chamada com recursão.
*   `04_quicksort/` — Estratégia dividir para conquistar e Quicksort.

## Como Executar os Códigos

1. Clone este repositório em sua máquina:
   ```bash
   git clone https://github.com/rubensrabelo/estrutura-de-dados.git
   ```
2. Acesse a pasta do algoritmo que deseja testar:
   ```bash
   cd 01_busca_binaria
   ```
3. Execute o arquivo:
   ```bash
   python busca_binaria.py
   ```
